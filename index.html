FAKE DRIVE CATCHER v1.0
===========================================
HARDWARE-LEVEL USB CAPACITY VERIFICATION
===========================================

A lightweight, bare-metal utility written in C++.

Fake Drive Catcher bypasses the Windows Operating System file cache to interact directly with the raw silicon of your USB drive. It performs spot-checks across the drive's claimed capacity to detect fraudulent, modified pendrives that loop their storage.
